2. Slicing: cortar un pedazo

lista[a:b] devuelve una lista nueva desde la posición a hasta antes de b.

102030405060
EscribesSignificaResultado
lista[1:4]de 1 hasta antes de 4[20, 30, 40]
lista[:3]los primeros 3[10, 20, 30]
lista[3:]de 3 hasta el final[40, 50, 60]
lista[-2:]los últimos 2[50, 60]
lista[1:-1]sin el primero ni el último[20, 30, 40, 50]
lista[::2]de 2 en 2[10, 30, 50]
lista[::-1]al revés[60, 50, 40, 30, 20, 10]

El inicio entra, el final no. [a:b] tiene b − a elementos.

3. Partir en dos mitades

mitad = len(lista) // 2
primera = lista[:mitad]
segunda = lista[mitad:]

Como el final no se incluye, las dos mitades no se pisan ni dejan huecos.

def leer_lista(n):
    lista = []
    for i in range(n):
        lista.append(int(input()))
    return lista


def main():
    lista = leer_lista(int(input()))
    print(min(lista))
    print(max(lista))
    print(sum(lista) // len(lista))
    print(lista[:3])
    print(lista[::-1])


main()
