Nivel 0.5 — Planas de Matrices

Dos índices, un solo patrón mental. Cuando lo automatices, nada te asusta.

⚠️ Reglas del curso: no uses .append(), f-strings, .map() ni comprensiones. Para crear matriz: [0] * n + for con matriz[i] = [0] * m. Siempre.

Ya dominas vectores. Ahora toca el salto a MATRICES — que es básicamente vectores dentro de vectores. El concepto es simple: en vez de un índice (i), ahora manejas dos (i para fila, j para columna). Esta sección te enseña por repetición hasta que ese "doble for" lo escribas sin pensar.

Varias filas. Dos índices: i escoge la fila, j la casilla dentro de esa fila.

Una matriz es un vector de filas. Cada fila es un vector de los que ya sabes llenar.

  • matriz[1] es la fila 1 completa: [5, 8, -1, 4].
  • matriz[1][2] es la casilla 2 de esa fila: -1.
  • La última casilla es matriz[n - 1][m - 1] = matriz[2][3] = 3.

Primero la fila, después la columna. Siempre. matriz[fila][columna].

3. El doble for

Para visitar todas las casillas, el for de i escoge una fila y, dentro, el for de j camina por ella. Cuando j termina la fila, i baja a la siguiente:

for i in range(n):          # filas: 0 .. n-1
    for j in range(m):      # columnas: 0 .. m-1
        matriz[i][j] = ...

En total n × m vueltas: una por casilla.

4. Crear la matriz: el único patrón permitido

matriz = [0] * n
for i in range(n):
    matriz[i] = [0] * m

Primero un vector de n casillas (las filas). Después, cada casilla se cambia por un vector de m ceros. Nunca uses:

  • ❌ [[0] * m for _ in range(n)] — es una comprensión.
  • ❌ matriz.append([0] * m) — es .append.
  • ❌ [[0] * m] * n — las n filas quedan siendo la misma lista: cambias una casilla y cambia en todas las filas.

La plana de funciones

En el examen la matriz se crea, se lee y se imprime en todos los ejercicios. Por eso se escriben una vez como funciones y main() las llama. Estas tres funciones son la plana del Nivel 0.5: escríbelas de memoria hasta que salgan solas.

Función 1 · crear_matriz · escríbela 3 veces

def crear_matriz(n, m):
    matriz = [0] * n
    for i in range(n):
        matriz[i] = [0] * m
    return matriz

Función 2 · leer_matriz · escríbela 3 veces

def leer_matriz(n, m):
    matriz = crear_matriz(n, m)
    for i in range(n):
        for j in range(m):
            matriz[i][j] = int(input())
    return matriz

Función 3 · imprimir_matriz · escríbela 3 veces

def imprimir_matriz(matriz, n, m):
    for i in range(n):
        linea = ""
        for j in range(m):
            if j > 0:
                linea = linea + " "
            linea = linea + str(matriz[i][j])
        print(linea)
