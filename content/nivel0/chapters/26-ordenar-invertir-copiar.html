✅ Se vale: métodos de listas, sum/min/max/len, slicing y for dato in lista. ❌ Sigue prohibido: f-strings y comprensiones.

Organiza tus datos sin escribir el algoritmo. Pero cuidado con el .copy().

Ordenar: dos formas

lista.sort() · cambia la misma

notas = [4, 1, 3]
notas.sort()
print(notas)   # [1, 3, 4]

La original queda ordenada. Devuelve None.

sorted(lista) · crea otra

notas = [4, 1, 3]
orden = sorted(notas)
print(notas)   # [4, 1, 3]
print(orden)   # [1, 3, 4]

La original no se toca.

Invertir

lista = [1, 9, 2]
lista.reverse()
print(lista)   # [2, 9, 1]  ← NO ordena, solo da la vuelta

De mayor a menor: primero .sort() y después .reverse() (o en un paso, .sort(reverse=True)).

⚠️ La trampa de la copia

lista1 = [1, 2, 3]
lista2 = lista1        # ❌ NO es copia, ambas apuntan a lo mismo
lista2 = lista1.copy() # ✅ SÍ es copia

❌ Asignación directa

lista1 = [1, 2, 3]
lista2 = lista1
lista2[0] = 99
print(lista1)  # [99, 2, 3] 😱

Una sola lista con dos nombres. Cambias por uno y se ve por el otro.

✅ Con .copy()

lista1 = [1, 2, 3]
lista2 = lista1.copy()
lista2[0] = 99
print(lista1)  # [1, 2, 3] 👍

Dos listas distintas con los mismos valores.

El = no copia listas: les pone otro nombre.

Otra trampa: asignar el sort

notas = notas.sort()   # ❌ notas queda en None
notas.sort()           # ✅

Esqueleto L4 · escríbelo 3 veces

def leer_lista(n):
    lista = []
    for i in range(n):
        lista.append(int(input()))
    return lista


def main():
    original = leer_lista(int(input()))
    ordenada = sorted(original)
    copia = original.copy()
    copia.reverse()
    print(original)
    print(ordenada)
    print(copia)


main()
