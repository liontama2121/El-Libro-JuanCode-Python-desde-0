Ahora · con append

lista = []

    lista.append(int(input()))

Esqueleto L2 · escríbelo 3 veces

def leer_lista(n):
    lista = []
    for i in range(n):
        lista.append(int(input()))
    return lista


def main():
    n = int(input())
    numeros = leer_lista(n)
    # aquí van los métodos que pide el enunciado
    print(numeros)


main()

Fila contra pila

Fila (cola) · el primero sale

fila = ["Ana", "Luis", "Sara"]
atendido = fila.pop(0)   # "Ana"

Como la fila del banco: atienden al que llegó primero.

Pila · el último sale

pila = ["rojo", "azul", "verde"]
plato = pila.pop()       # "verde"

Como una pila de platos: se toma el de arriba.

Tres trampas

TrampaQué pasa
a.append([4, 5])Mete la lista como una casilla: [1, 2, 3, [4, 5]]. Para pegar: .extend.
lista.remove(x) con x repetidoSolo quita el primero. Y si x no está, da error.
lista.pop() con la lista vacíaDa error. Revisa antes con if len(lista) > 0.

append al final, insert donde digas, pop saca y devuelve.
