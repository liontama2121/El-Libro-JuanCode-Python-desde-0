Cómo preguntarle a una lista qué contiene, sin recorrerla a mano.

Las tres preguntas

PreguntaEscribesDevuelve
¿Está?x in listaTrue / False
¿No está?x not in listaTrue / False
¿Cuántas veces?lista.count(x)un entero (0 si no está)
¿Dónde está?lista.index(x)la primera posición · error si no está

Antes · bandera a mano

esta = False
for i in range(n):
    if vector[i] == x:
        esta = True

Ahora · in

esta = x in lista

Antes · contador

cuenta = 0
for i in range(n):
    if vector[i] == x:
        cuenta = cuenta + 1

Ahora · count

cuenta = lista.count(x)

El patrón seguro de .index

.index se cae con ValueError si el valor no está. Por eso siempre se pregunta primero:

Esqueleto L3 · escríbelo 3 veces

def posicion(lista, x):
    if x in lista:
        return lista.index(x)
    return -1


def main():
    n = int(input())
    numeros = []
    for i in range(n):
        numeros.append(int(input()))
    x = int(input())
    print(posicion(numeros, x))


main()

Primero in, después index. Nunca al revés.

Todo esto funciona igual con textos: "ana" in usuarios. Ojo: distingue mayúsculas, "Ana" no es "ana".
