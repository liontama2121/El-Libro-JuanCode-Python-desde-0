⚠️ Reglas del curso: no uses .append(), f-strings, .map() ni comprensiones. Todos los vectores se crean con [0] * n y se llenan por índice. Siempre.

Ya sabes filtrar con un k. Este capítulo trae las otras tres sublógicas del patrón V: separar en dos vectores, reorganizar en uno solo y copiar con un giro. Son 18 ejercicios: la plana más larga del libro.

V-B. Separar: dos vectores, dos contadores

Esqueleto V-B · escríbelo 3 veces

grupo1 = [0] * n
grupo2 = [0] * n
k1 = 0
k2 = 0
for i in range(n):
    if vector[i] (condición):
        grupo1[k1] = vector[i]
        k1 = k1 + 1
    else:
        grupo2[k2] = vector[i]
        k2 = k2 + 1

Cada vector nuevo tiene su propio contador. Ambos nacen de tamaño n porque, en el peor caso, todos caen en el mismo grupo. Si hay elementos que no van a ninguno (como el cero entre positivos y negativos), el else se cambia por elif. Ejercicios: V-B.1 a V-B.6.

V-C. Reorganizar: un vector, un k, varias pasadas

Esqueleto V-C · escríbelo 3 veces

nuevo = [0] * n
k = 0
for i in range(n):              # pasada 1: el primer grupo
    if vector[i] (condición):
        nuevo[k] = vector[i]
        k = k + 1
for i in range(n):              # pasada 2: el resto (condición contraria)
    if vector[i] (contraria):
        nuevo[k] = vector[i]
        k = k + 1

for i in range(n):
    print(nuevo[i])

La clave: k no se reinicia entre pasadas. La segunda sigue escribiendo justo donde terminó la primera. Las condiciones deben ser opuestas exactas (> x con <= x), o algún elemento se pierde. Tres grupos = tres pasadas. Ejercicios: V-C.1 a V-C.6.
