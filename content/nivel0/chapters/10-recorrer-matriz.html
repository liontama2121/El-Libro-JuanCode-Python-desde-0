Contar y sumar en toda la matriz. Son los patrones II y III del Nivel 0 metidos en un doble for — y ahora dentro de una función que retorna.

Esqueleto M2-A · contar · escríbelo 3 veces

def contar(matriz, n, m):
    cuenta = 0
    for i in range(n):
        for j in range(m):
            if matriz[i][j] (condición):
                cuenta = cuenta + 1
    return cuenta

Esqueleto M2-B · sumar · escríbelo 3 veces

def suma_total(matriz, n, m):
    total = 0
    for i in range(n):
        for j in range(m):
            total = total + matriz[i][j]
    return total

Y en main(), después de leer: print(suma_total(matriz, n, m)).

El enunciado dice…Condición / cambio
positivosmatriz[i][j] > 0
paresmatriz[i][j] % 2 == 0
cerosmatriz[i][j] == 0
mayores a Xmatriz[i][j] > x (y x entra como parámetro)
cuántas veces aparece Xmatriz[i][j] == x
promediosuma_total(matriz, n, m) / (n * m)

Tres reglas: cuenta = 0 va antes de los dos for (no entre ellos); cuenta = cuenta + 1 va dentro del if; el return va afuera de los dos for.
