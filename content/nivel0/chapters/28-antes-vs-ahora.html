✅ Se vale: métodos de listas, sum/min/max/len, slicing y for dato in lista. ❌ Sigue prohibido: f-strings y comprensiones.

El cierre del Nivel 0. El mismo ejercicio resuelto de las dos formas, para que veas cuánto camino recorriste.

El ejercicio

Leer N números, filtrar los positivos, ordenarlos e imprimirlos.

Antes · Nivel 0, reglas estrictas

n = int(input())
vector = [0] * n
for i in range(n):
    vector[i] = int(input())

# Contar positivos
cuenta = 0
for i in range(n):
    if vector[i] > 0:
        cuenta = cuenta + 1

# Crear vector filtrado
positivos = [0] * cuenta
k = 0
for i in range(n):
    if vector[i] > 0:
        positivos[k] = vector[i]
        k = k + 1

# Ordenar (burbuja)
for i in range(cuenta - 1):
    for j in range(cuenta - 1 - i):
        if positivos[j] > positivos[j + 1]:
            aux = positivos[j]
            positivos[j] = positivos[j + 1]
            positivos[j + 1] = aux

# Imprimir
for i in range(cuenta):
    print(positivos[i])

Ahora · Nivel 0.6, con métodos

n = int(input())
positivos = []
for i in range(n):
    dato = int(input())
    if dato > 0:
        positivos.append(dato)

positivos.sort()

for dato in positivos:
    print(dato)

Sin contar antes, sin k, sin burbuja. Nueve líneas contra treinta.

Lo que antes era un algoritmo ahora es un método. Pero entiendes qué hace el método porque ya lo escribiste a mano.

¿Y entonces para qué sirvió el Nivel 0?

  • Cuando un método falle (.index que no encuentra, .pop en lista vacía), vas a saber por qué.
  • En algunos parciales y jueces siguen pidiendo las reglas estrictas: ya las tienes de memoria.
  • En el curso avanzado (ordenamientos, búsqueda binaria) vas a volver a escribir estos algoritmos a mano.

Esqueleto L6 · la versión con funciones

def filtrar_positivos(datos):
    positivos = []
    for dato in datos:
        if dato > 0:
            positivos.append(dato)
    return positivos


def main():
    n = int(input())
    numeros = []
    for i in range(n):
        numeros.append(int(input()))
    positivos = filtrar_positivos(numeros)
    positivos.sort()
    for dato in positivos:
        print(dato)


main()
