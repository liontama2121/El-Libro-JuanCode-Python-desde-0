⚠️ Reglas del curso: no uses .append(), f-strings, .map() ni comprensiones. Todos los vectores se crean con [0] * n y se llenan por índice. Siempre.

Cuenta cuántos elementos cumplen una condición. Es el 70% de los ejercicios de examen.

n = int(input())
vector = [0] * n
for i in range(n):
    vector[i] = int(input())

cuenta = 0
for i in range(n):

La plana de este patrón es cambiar solo la condición:

El enunciado dice…Condición
positivosvector[i] > 0
negativosvector[i] < 0
cerosvector[i] == 0
paresvector[i] % 2 == 0
imparesvector[i] % 2 == 1
mayores a 10vector[i] > 10

Tres reglas que no se negocian: cuenta = 0 va antes del for; cuenta = cuenta + 1 va dentro del if; el print va afuera, al final.
