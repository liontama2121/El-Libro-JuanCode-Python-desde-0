📋 Crear y modificar listas

1. Crear con corchetes

Nivel 0 · tamaño fijo

vector = [0] * 3
vector[0] = 1
vector[1] = 2
vector[2] = 3

Primero el tamaño, después cada casilla.

Nivel 0.6 · con corchetes

lista = [1, 2, 3]
vacia = []

Si ya conoces los datos, los escribes directo. [] es una lista vacía que después puede crecer.

3. Modificar una casilla

lista = [1, 2, 3]
lista[1] = 9
print(lista)      # [1, 9, 3]

Igual que en el Nivel 0: asignar a una posición la cambia. Y print(lista) ya se vale para mostrarla completa.

4. Mezclar tipos

ficha = ["Ana", 19, True]
print(ficha[0])   # Ana
print(ficha[1])   # 19

Una lista de Python acepta textos, números y booleanos juntos. Sirve para guardar una "ficha" con datos de distinto tipo.

5. Recorrer por valores

Por índice · para cambiar

for i in range(len(lista)):
    lista[i] = lista[i] * 2

Por valor · para leer

for dato in lista:
    print(dato)

Si solo vas a leer los valores, usa for dato in lista. Si vas a cambiar casillas, necesitas la posición i.
