Suma, promedio, totales. El patrón que resuelve "imprime el total de X".

Esqueleto III · escríbelo 3 veces

n = int(input())
vector = [0] * n
for i in range(n):
    vector[i] = int(input())

suma = 0
for i in range(n):
    suma = suma + vector[i]

print(suma)
