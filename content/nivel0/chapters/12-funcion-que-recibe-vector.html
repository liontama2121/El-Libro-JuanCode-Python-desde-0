⚠️ Reglas del curso: no uses .append(), f-strings, .map(), comprensiones ni global. Vectores con [0] * n. Siempre def + main() + última línea main().

La función recibe un vector completo. Adentro se puede llamar distinto que afuera.

Un vector entra a la función igual que un número: por un parámetro. Junto con él va su tamaño, porque la función no adivina cuántas casillas tiene.

Esqueleto F4 · escríbelo 3 veces

def imprimir_vector(v, tam):
    for i in range(tam):
        print(v[i])


def main():
    n = int(input())
    vector = [0] * n
    for i in range(n):
        vector[i] = int(input())
    imprimir_vector(vector, n)


main()

Es el mismo vector con otro nombre. Afuera es vector, adentro es v.

Lo de adentro es lo que ya sabes de las planas de vectores: contar, acumular, buscar máximo, filtrar con k. Lo único nuevo es que vive dentro de un def y termina en return.

Devolver un vector nuevo

Una función también puede crear un vector y devolverlo. Se crea con [0] * tam, se llena por índice y se retorna:

def invertir_vector(v, tam):
    nuevo = [0] * tam
    for i in range(tam):
        nuevo[i] = v[tam - 1 - i]
    return nuevo

Para filtrar, primero se cuenta cuántos cumplen (eso es el tamaño del vector nuevo) y después se copian con el contador k, como en la Parte II.
