Muchas funciones pequeñas y main() orquesta. Así se ve el código en el mundo real.

🔑 Scope: las variables de adentro son otras

Cada función es una casa con sus propias cosas adentro.

1. Qué es el scope

El scope es el lugar donde vive una variable. Una variable creada dentro de una función nace cuando la función empieza y muere cuando la función termina. Afuera nadie la ve.

Tu cuarto y el de tu hermano tienen cada uno una "cama". Son dos camas distintas aunque se llamen igual. Tú no puedes dormir en la de él desde tu cuarto.

Por eso en el esqueleto hay un total dentro de suma_vector y otro total en main(): son dos variables distintas. La de adentro se pierde; lo único que sobrevive es el valor que sale por el return.

2. El error clásico

❌ Así no

def leer_vector(tam):
    v = [0] * tam
    for i in range(tam):
        v[i] = int(input())


def main():
    n = int(input())
    leer_vector(n)
    print(v[0])    # NameError: v

v murió al terminar leer_vector. En main() no existe.

✅ Así sí

def leer_vector(tam):
    v = [0] * tam
    for i in range(tam):
        v[i] = int(input())
    return v


def main():
    n = int(input())
    numeros = leer_vector(n)
    print(numeros[0])

La función retorna el vector y main() lo guarda con su propio nombre.

3. Las 3 reglas del scope

ReglaConsecuencia
1. Lo que se crea adentro, se queda adentroPara sacar algo, return. Para guardarlo, variable = funcion(...)
2. Lo que una función necesita, se le pasaPor parámetro. Nunca con global
3. El mismo nombre en dos funciones son dos variablesEl i de leer_vector y el i de suma_vector no se pisan

4. Pop quiz

1. suma_vector crea total pero en main() no la guardo: suma_vector(numeros, n) y luego print(total). ¿Qué pasa?

NameError. El total de adentro murió. Hay que guardar el retorno: total = suma_vector(numeros, n).

2. Dentro de mayor(v, tam) uso n, que existe en main(). ¿Funciona?

No. n es de main(). Adentro el tamaño se llama tam, que es justo para eso: se lo pasaste por parámetro.

3. Dos funciones tienen cada una un for i in range(...). ¿Se dañan entre sí?

No. Cada una tiene su propio i. Viven en casas distintas.

La plana

Esqueleto F5 · escríbelo 3 veces

def leer_vector(tam):
    v = [0] * tam
    for i in range(tam):
        v[i] = int(input())
    return v


def suma_vector(v, tam):
    total = 0
    for i in range(tam):
        total = total + v[i]
    return total


def main():
    n = int(input())
    numeros = leer_vector(n)
    total = suma_vector(numeros, n)
    print(total)


main()

Cada función hace una sola cosa. main() no recorre ni cuenta: lee n, llama, guarda lo que le devuelven e imprime.

main() es el director de orquesta: no toca ningún instrumento, solo dice quién suena y cuándo.
